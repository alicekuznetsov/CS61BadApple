This repository was made as part of the [Project 0 Contest](https://sp26.datastructur.es/projects/proj0/#task-13-create-a-video-of-your-simulation-optional) for UC Berkeley's CS61B Course! (Data Structures)
Uploading the exact code run in the video is against course policy, so this repo only contains the Python code used to generate "board" strings that can be read by the provided `fromBoardString` method.

# Usage
If you'd like to see a version of Bad Apple running in your terminal, run `main.py` and enter in "terminal"! Otherwise, entering "proj0" will generate and write to an `output.txt` file, which you can use in Project 0 (after some modifications to allow it to read multiple board strings in sequence).
